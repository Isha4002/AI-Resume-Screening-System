# 🤖 AI Resume Screening System

## Overview

An AI-powered Resume Screening System built using NLP and Machine Learning.

This application compares a candidate's resume with a job description and provides:

* Resume Match Score
* Skill Gap Analysis
* Missing Skills Detection
* Candidate Evaluation

## Technologies Used

* Python
* Streamlit
* Scikit-Learn
* TF-IDF Vectorization
* Cosine Similarity

## Features

✅ Resume-Job Matching

✅ Match Percentage Score

✅ Progress Bar Visualization

✅ Missing Skills Detection

✅ Candidate Rating System

## How It Works

1. Paste Resume Text
2. Paste Job Description
3. Click Analyze
4. View Match Score and Missing Skills

## Example Output

* Match Score: 68.88%
* Candidate Rating: Good Match 👍
* Missing Skills:

  * Deep Learning
  * SQL
